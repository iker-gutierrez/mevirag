# GuiaSalud dev ablation summary

Supervisor-facing summary for the GuiaSalud (Spanish clinical guideline QA) dev ablation grid. Compares Qwen3.5-9B (no-think and think), Llama-3.1-8B-Instruct, and Latxa-Llama-3.1-8B-Instruct across the no-SF, single-corpus ablation cells (no cross-domain / mixed-domain variants, since GuiaSalud has no second corpus to cross or blend with).

## Experimental setup

- Dev set: GuiaSalud (`data/processed/guiasalud/dev.jsonl`).
- Generators: Qwen3.5-9B (no-think / think), Llama-3.1-8B-Instruct, Latxa-Llama-3.1-8B-Instruct.
- Main prompt family: cleaned extractive prompt.
- Retrieval index: `models/retrieval/guiasalud_train_multilingual_e5_large` (multilingual-e5-large dense index over GuiaSalud train+dev+test).
- Reranker: `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1` (retrieve top 15, then rerank).
- Run IDs: 3281-3316 (configs/experiments/3281_*.json .. 3316_*.json).
